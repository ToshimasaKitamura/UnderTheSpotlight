# ゲームフロー完全ガイド

## シーン遷移の流れ

```
TitleScene (タイトル)
    ↓ [START選択 + フェード遷移]
WorldMapScene (ワールドマップ)
    ↓ [ステージ選択 + スライド遷移]
CharacterSelectScene (キャラクター選択)
    ↓ [4人選択完了 + ワイプ遷移]
BattleScene (バトル)
    ↓ [バトル終了 + フェード遷移]
ResultScene (リザルト)
    ↓ [CONTINUE or TITLE + フェード遷移]
    ├→ WorldMapScene (次のステージへ)
    └→ TitleScene (タイトルへ戻る)
```

## 各シーンの操作方法

### 1. TitleScene (タイトル画面)

**操作:**
- 任意のキー/ボタン: メニュー表示
- ↑/↓ または W/S: メニュー選択
- Enter/Space/Z または ゲームパッドA: 決定
- Escape/X または ゲームパッドB: キャンセル

**メニュー:**
- Game Start: ワールドマップへ
- Options: (未実装)
- Exit: ゲーム終了

**遷移エフェクト:** フェードアウト → フェードイン

---

### 2. WorldMapScene (ワールドマップ)

**操作:**
- ←/→ または A/D: カーソル移動
- Enter/Space/Z または ゲームパッドA: ステージ選択・決定
- Escape/X または ゲームパッドB: タイトルへ戻る

**機能:**
- ステージ選択
- 進行状況の表示
- クリア済みステージの確認

**遷移エフェクト:** スライドイン → スライドアウト（左から右へ）

---

### 3. CharacterSelectScene (キャラクター選択)

**操作:**
- ←/→/↑/↓ または W/A/S/D: キャラクター選択
- Enter/Space/Z: 決定
- Escape: ワールドマップへ戻る

**デバッグモード:**
- 1/2/3/4キー押しながら: 特定のプレイヤーを操作
- キーなし: 最後に操作したプレイヤーを操作

**表示:**
- 左側: スポットライト演出でキャラクター1人を大きく表示
  - キャラクター画像
  - 名前・役割・説明文
  - パーティクルスポットライト（キャラクターのテーマカラー）
- 右側: 各プレイヤーの選択状況（P1〜P4）
- 下部: キャラクター選択グリッド（各プレイヤーの枠が色分け表示）

**特徴:**
- 4人全員が選択を完了すると自動的にバトルへ遷移
- 同じキャラクターを複数人が選択可能
- キャラクター切り替え時にフェード・回転アニメーション

**遷移エフェクト:** ワイプ遷移（円形拡大）

---

### 4. BattleScene (バトル)

**操作:**
- カードゲーム形式のバトル
- ミニゲームによる攻撃・防御
- 詳細は BattleStateMachine および各種フェーズクラスを参照

**遷移エフェクト:** フェードアウト → フェードイン

---

### 5. ResultScene (リザルト画面)

**操作:**
- Z または ゲームパッドA: ワールドマップへ（CONTINUE）
- X または ゲームパッドB: タイトルへ（TITLE）

**表示:**
- 勝利時: "VICTORY!" + "STAGE CLEAR!"
  - 金色のテキスト
  - スター演出（上昇アニメーション）
  - 脈動エフェクト
- 敗北時: "GAME OVER"
  - 赤色のテキスト
  - 画面シェイク（最初の1秒）
  - 控えめなスター演出

**遷移エフェクト:** フェードアウト → フェードイン

## シーン遷移システム (SceneTransitionManager)

全てのシーン遷移は `SceneTransitionManager` シングルトンによって管理されています。

### 遷移エフェクトの種類:

1. **フェード遷移** (`LoadSceneWithFade`)
   - 黒い画面にフェードアウト → シーンロード → フェードイン
   - 使用箇所: Title ↔ WorldMap, Battle → Result, Result → Title/WorldMap

2. **スライド遷移** (`LoadSceneWithSlide`)
   - パネルが左から右へスライドして画面を覆う → シーンロード → 右へ抜ける
   - イージング: EaseInOutCubic（滑らかな加速・減速）
   - 使用箇所: WorldMap → CharacterSelect

3. **ワイプ遷移** (`LoadSceneWithWipe`)
   - 画面中央から円形に広がる黒い幕 → シーンロード → 縮小して消える
   - 使用箇所: CharacterSelect → Battle

### カスタマイズ方法:

`SceneTransitionManager` インスタンスで以下のパラメータを調整可能:
- `fadeDuration`: フェード時間（デフォルト: 0.5秒）
- `slideDuration`: スライド時間（デフォルト: 0.6秒）

## ゲーム進行のポイント

### 初回プレイ時:
1. TitleScene でスタート
2. 任意のキーでメニュー表示
3. "Game Start" を選択してワールドマップへ
4. ステージを選択
5. 4人のキャラクターを選択（重複OK）
6. バトル開始
7. 勝利/敗北後にリザルト表示
8. CONTINUE で次のステージへ、または TITLE でタイトルへ

### キャラクター選択のコツ:
- 基本攻撃/防御/回復: バランス型パーティ
- 特殊攻撃/防御/回復: リスク＆リターン型
- デッキ破壊: 全カード使用の特殊戦術
- ランダム要素: 運要素を楽しむ

### デバッグ機能:
- キャラクター選択で 1〜4 キーを押すと、そのプレイヤーのカーソルを直接操作可能
- これにより4人分を素早く選択可能

## 技術的な詳細

### GameSceneManager
- シーン間でデータを保持するシングルトン
- `selectedStage`: 選択されたステージ
- `selectedCharacter`: 1人目のキャラクター（後方互換性）
- `selectedParty`: 4人全員のキャラクター配列
- `isVictory`: 勝敗フラグ

### SceneTransitionManager
- DontDestroyOnLoad でシーン間を永続
- Canvas（SortingOrder: 9999）で最前面表示
- コルーチンによる非同期シーンロード
- イージング関数による滑らかなアニメーション

## トラブルシューティング

### 遷移エフェクトが表示されない:
- SceneTransitionManager が初期化されているか確認
- Canvas の SortingOrder が最前面か確認

### シーンが見つからない:
- ProjectSettings/EditorBuildSettings.asset に全シーンが登録されているか確認
- シーン名が GameSceneManager.Scenes クラスの定数と一致しているか確認

### キャラクター選択で画像が表示されない:
- Resources/CharacterData/ にキャラクターデータが保存されているか確認
- Player.png スプライトシートが正しく分割されているか確認
