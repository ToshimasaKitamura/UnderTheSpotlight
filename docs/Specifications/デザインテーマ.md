# デザインテーマ仕様（フォント / テーマカラー）

このゲーム「アンダーザスポットライト」の**見た目の正典**。テーマは **舞台 / 劇場 × 8bit ドット絵**。
実装は [`GameColorScheme`](../../Assets/Src/Utils/GameColorScheme.cs)（色）と [`GameFont`](../../Assets/Src/Utils/GameFont.cs)（フォント）。
**この文書の値とコードは常に一致させる**（片方だけ変えない）。

## 決定（2026-08-03）

- **主フォント = PixelMplus12**（無ければ PixelMplus10 → 同梱 misaki_gothic にフォールバック）
- **カラーテーマ = ステージパープル**（下記の3テーマ色＋基本パレット。プレビュー B案「A. ステージパープル」）
- 選定の視覚比較: [../デザイン案/テーマ案.html](../デザイン案/テーマ案.html)

## フォント

方針: **ドットっぽさ（レトロ感）と可読性の両立**。

| 役割 | フォント | 備考 |
|---|---|---|
| **主フォント（決定）** | **PixelMplus（ピクセルＭＰＬＵＳ）12 / 10** | ドット＋高可読の日本語ビットマップ体。`Assets/Resources/Fonts/PixelMplus12.ttf`（および10）を配置すると自動で有効化 |
| 同梱・フォールバック | **美咲ゴシック（misaki_gothic）** | 8px。既に同梱済み。PixelMplus 未配置時に使用 |
| 最終手段 | LegacyRuntime(組み込み) | 欧文のみ。上記が無い異常時のみ |

- **入口は [`GameFont.Body()`](../../Assets/Src/Utils/GameFont.cs) の1本**。UI から直接 `Font.CreateDynamicFontFromOSFont` を使わない（Unity 6 の IMGUI で例外＝ラベル破壊。[../開発ナレッジ.md](../開発ナレッジ.md) 参照）。
- 解決順: `PixelMplus12(-Regular)` → `PixelMplus10(-Regular)` → `misaki_gothic`（すべて `Assets/Resources/Fonts/` 内）。公式配布名 `PixelMplus12-Regular.ttf` のままでも、`PixelMplus12.ttf` にリネームしても認識する。
- **可読性のためのサイズ運用**: ビットマップ体はにじみ防止のため**整数倍で拡大**する。本文は概ね `pixelScale*6` 以上、見出しは `pixelScale*10` 前後（`pixelScale = max(2, Screen.height/360)`）。
- PixelMplus は IPA/M+ 系ライセンス。配置時は同梱ライセンス表記を守る。

## 実装の対応（コード ↔ 仕様）

- 色: [`GameColorScheme`](../../Assets/Src/Utils/GameColorScheme.cs) の `Main` / `Sub` / `Accent` / `Background` / `Surface` / `TextOnDark` / `TextMuted` / `Success` / `Warning` / `Danger` / `Players[]`。
  - 既存の `Primary*` / `Accent*` / `*Zone*` などは、上記テーマ色から派生した「用途別の濃淡」。新規UIは原則 3テーマ色＋基本パレットを使う。
  - **テーマ適用済みの画面**（ハードコード色を撤去しトークン直接参照）: タイトル（`TitleView`）／ゲームオーバー（`ResultSceneController`）／キャラ選択（`TempCharacterSelectController`）／ワールドマップ（`WorldMapView`）。バトルの背景・弾幕枠（`BattleBackgroundView`/`DanmakuFrameView`）は既存の派生色を使用。
- フォント: [`GameFont.Body()`](../../Assets/Src/Utils/GameFont.cs)。
- **変更手順**: 値を変えるときは、この文書の表と `GameColorScheme` / `GameFont` を同時に直し、`bash Tools/check_all.sh` を通す。
