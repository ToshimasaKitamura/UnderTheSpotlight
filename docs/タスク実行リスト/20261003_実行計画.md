## 1. 今回のスコープと方針

- **スコープ**: 「一巡だけマジで完成させる版」= **World1 のステージ2まで**。
  - ステージ1 = **ボスA**（単体）
  - ステージ2 = **ボスB → ボスC** の連戦
- **実施順序の方針**: **縦に1本完成優先**。まずステージ1（ボスA）を最初から最後まで遊べる形に完成させ、その実績を元にボスB/C・ステージ2へ横展開する。
- **カード**: 今回は **一巡を成立させる最小限のみ実装**。「数百枚オーダー」は分類・設計指針・総量だけを**見積りドキュメント化**に留める（実装は今回スコープ外）。
- **ボスの個性**: A/B/C それぞれに **固有の弾幕パターン + 見た目（スプライト） + 難易度パラメータ（弾数/弾速）** を与え、3体がはっきり違うと感じる水準まで作り込む。コンセプトは §7 に定義。
- **開発方針**: 一巡の実タスク/工数から**ゲーム全体の総量を見積もる**。ローカル開発時は**コントローラ2つ**を繋いで多人数プレイを検証する。

### 着手前の確定事項（2026-10-03）

- **回復弾**: 見た目だけでなく**効果（ボスの自己回復）まで実装**する。
- **速度ランプ**: `GameTuning` のラウンド速度上昇（`speedRampPerRound`/`difficultyToSpeed`）を**今回有効化**し、弾幕パターンに接続する。
- **ボスのコンセプト**: 既存案なし。本書 §7 に新規定義（劇場テーマに準拠）。

## 7. ボスコンセプト（提案 — 劇場テーマ準拠）

世界観 = **舞台/劇場 × スポットライト**（[デザインテーマ](../Specifications/デザインテーマ.md)）。「舞台の演者」として3体を設計し、難易度と弾種で個性を分ける。難易度は **A < B < C**。

見た目は `Assets/Images/Test.png`（`AllChara_N` スプライト）のチップを流用。A=暖色 / B=黒・橙 / C=白・青 で一目で区別できる3体を選定（2026-10-03）。

| | ボスA（Stage1） | ボスB（Stage2前半） | ボスC（Stage2後半/トリ） |
|---|---|---|---|
| **スプライト** | **AllChara_85**（赤髪＋輪回し） | **AllChara_136**（黒衣＋鋭い炎） | **AllChara_134**（白髪＋周回オーブ） |
| **役割** | 前座・入門 | 中ボス・手応え | 大トリ・ギミック |
| **コンセプト** | 道化のジャグラー（お手玉/輪回し芸人） | ナイフ投げ師（黒衣の刺客） | 座長／指揮者（弾を操るマエストロ） |
| **弾幕の性格** | 弧を描く素直なばらまき弾。パターンを覚えやすい | 直線の鋭い**速弾（クナイ）**中心。狙い撃ち | 複数パターンを切替。**緑の回復弾**を自分に飛ばし自己回復するギミック |
| **主な弾種** | 通常（白黒） | 通常 + 速弾（クナイ） | 通常 + 速弾 + **回復弾（緑）** |
| **難易度パラメータ** | 弾数・弾速ともに低 | 弾速高め・弾数中 | 弾数多・弾速高・複合 |
| **狙い** | 弾幕回避の操作に慣れさせる | 1種の脅威（速さ）に集中対処させる | 回復弾を避け続け、手数で押し切らせる＝一巡の山場 |

> 弾種要件（白黒=基本 / 速弾=クナイ的 / 緑=回復）を A→B→C で段階的に導入する構成。スプライトは `AllChara_N` を変えれば差し替え可能（代替候補: C に AllChara_127＝金の杖演出 など）。現状 `BossIntroPhase.LoadBossSprite()` は `AllChara_0` 固定なので、Phase 0-4 で EnemyData 側の指定を読むよう改修する。実装は 1-1/1-2（A）→ 2-2（B）→ 2-3（C）。
