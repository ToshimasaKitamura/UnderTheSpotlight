## 2026-08-03 「FSTimeGet … folder exists no」が多発する
- **症状**: Unity ログに `currentFileSystemTime.ticks != 0 using check file Temp/FSTimeGet-… (file exists no, folder exists no)` が繰り返し出る
- **原因**: **ドメインリロード(再コンパイル)のたびに Unity 6000.3.13f1 が出す無害な診断ログ**。「folder exists no」は誤表示（`Temp/` は実在・書込可・ディスク余裕あり）。多発の理由は大量のリロード＝①6000.0.54f1→6000.3.13f1 更新で Library 全再構築中 ②スクリプト多数編集で毎回再コンパイル。各行の直後にアセンブリ再読込とアセット取込が**成功**しており停止ではない。`error CS` はゼロ
- **切り分け**: `Editor.log` 末尾で FSTimeGet 直後に `Loaded All Assemblies` / `Start importing …` が続くか（＝正常進行）。`ls -ld Temp` と `touch Temp/x` で実在・書込を確認
- **対処**: 無視でよい。Library 再構築とアセット取込の完了＋編集停止で自然に止む。完了・アイドル後も延々出続ける場合のみ、6000.3.13f1×日本語パス(`アンダーザスポットライト`)の相性を疑い 6000.0.54f1 へ戻す/英数字パスへ移設を検討
- **再発防止(別件)**: `Temp/`・`Library/`・`Logs/` は Unity 管理下。**Unity 起動中に消さない**（掃除は閉じてから）。CLAUDE.md 昇格済み
- **関連**: `~/Library/Logs/Unity/Editor.log`, `ProjectSettings/ProjectVersion.txt`

## 2026-08-03 「カーソルにして」の指示で“何も選べない”状態を作ってしまった
- **症状**: キャラ選択をカーソル方式にしたが、カーソルを左のキャラリスト(カード)に重ねても**選択できない**。加えて旧ボタン方式の**カード背景の色枠**が残っていた
- **原因**:
  1. 要求された入力方式を**確認せず「マウス」と早合点**した(実際はゲーム＝カード選択と同じ**キーボード**でカーソル移動が正)
  2. 当たり判定 `RectTransformUtility.RectangleContainsScreenPoint(rt, pos, camera)` に **camera=null(Overlay用)** を渡したが、対象 Canvas は **ScreenSpaceCamera(RenderMode:1)** のため判定が成立せず、カーソル位置で何も掴めなかった
  3. 旧演出(`SetPlayerCursors`→`playerFrames` の色枠)を消し忘れた
- **対処**: 入力を**キーボード移動に統一**(CardSelectPhase と同モデル)／当たり判定に **Canvas の worldCamera** を渡す(Overlay なら null)／`UpdateUI` から色枠更新を除去し起動時に全消灯
- **なぜ起きたか(プロセス上の根因)**: 「**何を・どの入力方式で選択させるか**」を確認も仕様参照もせず実装したため、入力方式(マウス/キーボード)も当たり判定の前提(Canvas 描画モード)も外した
- **再発防止(対策)**:
  - 選択UIを作る前に「**何を選択できるようにするか／どの入力で操作するか**」をユーザーに質問する。または既存の同種画面(例: `CardSelectPhase`)・仕様書([Specifications/GAME_FLOW.md](Specifications/GAME_FLOW.md))を見て**その画面で何を選べるはずか**を判断してから実装する
  - uGUI の座標ヒット判定は必ず **Canvas の RenderMode を確認**し、`RectangleContainsScreenPoint` に正しい camera(Overlay=null / Camera・World=worldCamera)を渡す
- **関連**: [Assets/Src/Character/CharacterSelectSceneController.cs](../Assets/Src/Character/CharacterSelectSceneController.cs), [Assets/Src/Card/CardSelectPhase.cs](../Assets/Src/Card/CardSelectPhase.cs)

## 2026-07-27 ゲームオーバーのボタンにシーン名（DontDestroyOnLoad / ResultScene）が表示される
- **症状**: ボタンのラベルが日本語ではなく「DontDestroyOnLoad」「ResultScene」等になる
- **原因**: `GUI.Button` のラベル描画中に毎フレーム例外。`GameFont.Body()` が返す `Font.CreateDynamicFontFromOSFont`（動的OSフォント）を、Unity 6 の IMGUI(TextCore) が `FontAsset.CreateFontAsset` で変換しようとして例外を投げ、ラベルが壊れていた（Editor.log のスタックで特定）
- **対処**: `GameFont.Body()` を、インポート済みフォント `Resources/Fonts/misaki_gothic` を最優先で返すよう変更。これで ResultScene のボタンとアクションコマンドUIの両方が解消
- **再発防止**: IMGUI の日本語は動的OSフォントを使わず、インポート済みフォントを使う（CLAUDE.md 昇格済み）
- **関連**: [Assets/Src/Utils/GameFont.cs](../Assets/Src/Utils/GameFont.cs)
