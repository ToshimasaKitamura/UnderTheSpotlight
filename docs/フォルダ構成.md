# フォルダ構成（正）

このプロジェクトの**正式なフォルダ構成**と、新規ファイルの置き場所ルール。
新しいファイルを追加するときは必ずこの表に従う。逸脱がないかは `Tools/check_folder_structure.sh` で自動チェックできる（下記「維持の仕組み」参照）。

## トップレベル（Assets/ 直下）

| フォルダ | 用途 | 置くもの |
|---|---|---|
| `Assets/Src/` | ランタイムのC#スクリプト | **必ずドメイン別サブフォルダに**分類して置く（直下に .cs を置かない） |
| `Assets/Editor/` | エディタ拡張スクリプト | `UnityEditor` を使うもの（MenuItem/EditorWindow/CustomEditor 等）。※プレイヤービルドに含めないため必須 |
| `Assets/Scenes/` | シーン | `.unity` のみ |
| `Assets/Prefabs/` | プレハブ | `.prefab` |
| `Assets/Resources/` | 実行時 `Resources.Load` で読むもの | `Fonts/`, `Cards/`, `Images/`, `Data/` 等 |
| `Assets/Data/` | ScriptableObject データ | `Characters/`, `Enemies/`, `Stages/`, `Cards/`, `csv/`, `GameTuning.asset` 等 |
| `Assets/Images/` | スプライト/画像 | `.png` 等 |
| `Assets/Settings/` | URP 等のレンダリング設定 | Render Pipeline アセット類 |
| `Assets/TextMesh Pro/` | TMP パッケージ標準 | （原則さわらない） |

> `Assets/_Recovery/` は Unity の自動バックアップ残骸であり**正式な構成ではない**。中身は復旧用の一時ファイルなので、必要なければ削除してよい。

## Assets/Src のドメイン別分類

| サブフォルダ | 役割 |
|---|---|
| `Battle/` | バトル全体の進行・状態遷移（BattleStateMachine 等） |
| `Card/` | カード選択フェーズ・手札 |
| `Character/` | キャラクターデータ・キャラ選択 |
| `Dodge/` | 弾幕回避フェーズ |
| `Enemy/` | 敵・ボスのパターン |
| `MicroGame/` | アクションコマンド等のミニゲーム |
| `Network/` | オンライン対戦（ロビー/部屋コード・Netcode+Relay） |
| `System/` | シーン遷移・タイトル/リザルト等のシーン管理 |
| `UI/` | 汎用UI表示（ゲージ・アナウンス・フレーム等） |
| `Utils/` | 共通ユーティリティ（フォント・弾・描画等） |

- 新しいドメインが必要になったら、`Assets/Src/<新カテゴリ>/` を作ってからその中に置く（Src 直下に直接 .cs を置かない）。
- 既存のどれかに収まるならそこへ。無理に新カテゴリを増やさない。

## プロジェクトルート（Assets 外）

| 場所 | 用途 |
|---|---|
| `Docs/` | ドキュメント（本書・[開発ナレッジ.md](開発ナレッジ.md)・設計/仕様） |
| `Docs/デザイン案/` | 視覚で確認する案（配色・フォント等のプレビュー HTML など）。決定後の正典は `Specifications/` 側 |
| `Tools/` | 開発補助スクリプト（構成チェック等。Unity にインポートされない） |
| `.claude/` | Claude Code 用の設定・スラッシュコマンド |
| `CLAUDE.md` | Claude 向けの常設ルール |

## 配置ルール（要点）

1. ランタイム .cs → `Assets/Src/<カテゴリ>/`（Src 直下・Assets 直下に置かない）
2. エディタ専用 .cs（`using UnityEditor;` 等）→ `Assets/Editor/` 配下（**必須**。でないとビルドが壊れる）
   - ランタイム側で一部だけエディタAPIを使う場合は `#if UNITY_EDITOR` で囲み、`UnityEditor.` 完全修飾で呼ぶ（`using UnityEditor;` は書かない）
3. `.unity` → `Assets/Scenes/` のみ / `.prefab` → `Assets/Prefabs/`
4. `Resources.Load` で読むアセットだけ `Assets/Resources/` に置く（それ以外を Resources に入れない＝ビルドサイズ肥大の原因）

## 維持の仕組み

- **自動チェック**: `bash Tools/check_folder_structure.sh` で上記ルールの逸脱を検出（違反があれば終了コード 1）。
- **Claude Code フック**: `.claude/settings.json` の PostToolUse により、ファイルを追加/編集するたびに自動実行され、逸脱があればその場で報告される。
- 新規ファイル追加・移動をしたら、このチェックが通ることを確認してから完了とする。
- 構成そのものを変更した場合（新カテゴリ追加等）は、**本書とチェックスクリプトの両方を更新**する。
